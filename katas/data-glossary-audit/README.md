# Data Glossary Audit

## Goal

The goal of this kata is to audit a data glossary and identify any missing or incorrect definitions.

## Steps

1. Briefly Read [ISO/IEC 11179-4:2004(E)](<https://cdn.standards.iteh.ai/samples/35346/e1828b73c98b4fbca61fe950da0b7748/ISO-IEC-11179-4-2004.pdf>)

3. Start writing the agent code in main.py evaluating as you go!
